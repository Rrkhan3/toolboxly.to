Image Cropper

Crop images to the exact size or region you need. Free online image cropper that runs in your browser.

Your image is processed locally in your browser and is never uploaded.

Advertisement

How to use the Image Cropper

  1. Upload an image.
  2. Select the crop region using the on-page controls.
  3. Apply the crop and preview.
  4. Download the cropped result.

How it works

Pixels outside the selected rectangle are discarded; the remaining region is exported as a new image file via canvas APIs in the browser.

Useful for profile photos, product shots and removing unwanted edges.

Examples

  • Crop a landscape photo to a square for a profile avatar.
  • Remove borders from a scanned document image.
  • Focus on a subject by trimming background.

Image Cropper FAQ

Can I crop to an exact pixel size?

Use the crop selection and any size inputs the page provides to control the output region.

Is the original file modified on disk?

No. You download a new cropped file; your original stays unchanged.

Is the Image Cropper free?

Yes.
