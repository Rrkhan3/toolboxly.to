JavaScript Formatter

Use this free online javascript formatter to format and preview JavaScript. It works right in your browser, with no sign-up.

Everything runs in your browser. Your input is not sent to a server. Previews run in an isolated sandboxed frame and only when you press Run Preview.

How to use the JavaScript Formatter

  1. Paste or type your code or text into the input editor.
  2. Press the action button (Format, Validate, Encode, Decode or Generate).
  3. Copy or download the output. HTML, CSS and JavaScript tools also offer a sandboxed Preview tab.

How it works

The code is scanned character by character and re-indented: braces open and close indented blocks, semicolons end statements, and strings and comments are left untouched. The formatter never runs your code. Preview runs your HTML, CSS and JavaScript in a sandboxed frame, only when you press Run Preview.

Example

console.log("Hi") is placed on its own line, and Run Preview prints Hi in the console panel.

JavaScript Formatter FAQ

Does my JavaScript run on the ToolBoxy page?

No. It runs only when you press Run Preview, inside an isolated sandboxed frame with no access to ToolBoxy, its storage or cookies.

Does the formatter check syntax?

No. It only re-indents code. Errors show in the console when you run the preview.

Is the JavaScript Formatter free to use?

Yes. It is free, needs no account and runs in your browser.
