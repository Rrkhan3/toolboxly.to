CSS Formatter

Use this free online css formatter to format and preview CSS. It works right in your browser, with no sign-up.

Everything runs in your browser. Your input is not sent to a server. Previews run in an isolated sandboxed frame and only when you press Run Preview.

Advertisement

How to use the CSS Formatter

  1. Paste or type your code or text into the input editor.
  2. Press the action button (Format, Validate, Encode, Decode or Generate).
  3. Copy or download the output. HTML, CSS and JavaScript tools also offer a sandboxed Preview tab.

How it works

Each declaration is placed on its own line and rules are indented, including nested blocks such as media queries.

Example

a{color:red;margin:0} becomes a three-line rule.

CSS Formatter FAQ

Does it validate CSS?

No. It only formats the code.

Does it handle media queries?

Yes. Nested blocks are indented.

Is the CSS Formatter free to use?

Yes. It is free, needs no account and runs in your browser.
