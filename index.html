    Frequently Asked Questions

    What is ToolBoxy?

    ToolBoxy is a free collection of online utilities: calculators, text tools, developer tools, image tools and unit converters.

    Are ToolBoxy tools free?

    Yes. All tools can be used for free.

    Do I need to create an account?

    No. There is no sign-up or login.

    Are my files uploaded?

    No. ToolBoxy is a static website, and all tools, including the image tools, process your data locally in your browser.

    What types of tools are available?

    Calculators, text tools, developer tools, image tools and converters. New tools are added over time.
